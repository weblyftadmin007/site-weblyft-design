How to judge

A portfolio is easy to stage. These four tests are not.

How to check any web designer's portfolio

Pretty screenshots prove very little. Open the live sites and run these four checks before you shortlist anyone, including me.

  1. 01

    Load it on a phone on mobile data

    If the first screen takes more than two or three seconds, the build has not solved the main problem. Google's guidance is 2.5 seconds or less for Largest Contentful Paint.

  2. 02

    Tap the main button

    Call, book, reserve, request a quote: whatever the site promises. If the tap leads nowhere, nothing else on the page matters.

  3. 03

    Read the page with JavaScript off

    Turn off JavaScript and reload. If the text disappears, the site was built so search engines and answer tools have to guess.

  4. 04

    Search the business name

    A site you cannot find by its own name is not finished. Look for a Google Business Profile, a working phone number and matching details.
